# DIAPOSITIVAS JENKINS

## USO

Mediante el uso de una tecnología como Marp, podemos aprovechar el formato .md para crear diapositivas

---
Podemos diferenciar entras las distintas diapositivas utilizando --- , conteniendo entre bloques con dichos carácteres los distintos bloques a desarrollar

---
Además, podemos utilizar los encabezados de markdown (#,##,###...) para marcar diferentes títulos dentro de un posible índice

---

## Otros usos

Marp tambien es capaz de interpretar código html y css, permitiendonos personalizar el color y estilo de los elementos que utilicemos durante la presentación mediante ciertas sentencias como "<!-- size: 16:9 -->" para definir el tamaño que ocuparán, o 
"<style> h1 h2 </style>" ... para personalizar los distintos encabezados
